How it works

Four steps, one agent.

The toolkit gives your coding agent a brief, a set of fetch scripts and a strict sourcing policy. You bring the story.

  1. Install

    One npx command copies the toolkit in and sets up a Python virtual environment.

  2. Write

    Edit script.md: narration lines, chapters, and cues for the visuals you want.

  3. Fetch

    The agent runs the scripts. Each file lands in assets/ with its source and license logged.

  4. Build

    Scenes are timed to your voiceover in HyperFrames, with chapter reveals and credits.

# script.md
## Chapter 1: The Beginning
[CHAPTER: The Beginning | subtitle=Rented office, 2010]
In 2010, a small team in a rented office had an idea nobody believed in.
[FOOTAGE: startup office team working | duration=6]
The press noticed quickly.
[ARTICLE: https://example.com/launch | selector=article | highlight="nobody believed"]
Cue types

Say what you want to see.

A cue looks like [TYPE: search phrase | option=value]. Each type maps to a script in scripts/.

FOOTAGE

Stock video from Pixabay, then Pexels. duration, orientation

IMAGE

Stock photo from Pixabay, then Pexels. orientation

LOGO

Company logo from Wikimedia Commons or a press kit.

PERSON

Transparent cutout, styled with a white torn edge and soft shadow. hint

ARTICLE

Web article screenshot with the key sentence highlighted. selector, highlight

NEWSPAPER

Archive or front-page screenshot. fullpage

SFX

Small tactile sounds from Freesound, CC0 and CC BY only.

CHAPTER

Sets the title and subtitle of the reveal card between chapters. subtitle

Sourcing

Real sources, logged every time.

No generated media. The agent works down four tiers and stops at the first good result, writing the URL, license and tier of every file to assets/manifest.json.

T1

Free API or open license

Pixabay, Pexels, Wikimedia Commons, and public domain archives such as NASA and the Library of Congress.

T2

Free to reuse, license checked per file

Flickr Creative Commons, Unsplash, company press kits, official institutional media pages.

T3

Commentary only, cited and flagged

Screenshots of articles, archives and public posts. Listed in the credits and the final report for review.

T4

Ask you

Never scraped from Getty, Shutterstock, AP, Reuters, Alamy or paywalled sites.

Get started

Ready in a few minutes.

You need Python 3 and Node. init.py creates a .venv, installs the packages and Chromium, and creates your .env.

# 1. in your project folder
npx github:prantosmss/vox-toolkit

# 2. paste your keys into .env, then tell your agent:
Read instructions.md and build the documentary from script.md.

# run any script by hand with the venv Python
.venv/bin/python scripts/fetch_all.py script.md
PIXABAY_API_KEY

Stock footage and images.

PEXELS_API_KEY

Fallback stock footage and images.

FREESOUND_API_KEY

Sound effects. Music is yours: put royalty-free tracks in assets/music/.
